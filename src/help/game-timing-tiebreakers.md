These two sections set how long games are, how they are split into periods, and how tied teams are ranked in standings.

**Where:** **Setup → Tournament setup → Game Timing & Format** and **Standings tiebreakers**.

**To set game timing:**
1. Set **Schedule Increment (min)**, the time between game start slots. The Scheduler spaces games by this number.
2. Set **Game Length (min)** and **Break Between Games (min)**. These are for reference only for now.
3. Under **Game format**, pick the **Period format**: **Halves**, **Quarters**, **Periods** or **Running clock**.
4. Set the **Time between** halves, quarters or periods (min). The live scorekeeper app uses this for period labels and the break it shows.
5. Click **Save Changes**.

**To set tiebreakers:**
1. Under **Tie breakers within pools**, pick **Tie breaker #1**, **#2** and so on. #1 is applied first.
2. Under **Tie breakers within divisions**, do the same for ranking teams across pools (used for seeding).
3. Choices: **Record**, **Winning Percentage**, **Head to Head**, **Head to Head Two Teams Only**, **Head to Head Goal Diff**, **Goal Diff**, **Goals Scored** and **Goals Allowed**.
4. Click **Save Changes**.

**Save as default for new tournaments** stores this tiebreaker order for tournaments you create later.

**Common problems:**
- Head-to-head currently compares two tied teams directly.
