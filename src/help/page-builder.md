The event page is the public landing page for the tournament: overview, fees, divisions, location, hotels, rules, contacts and any blocks you add. You build it inside Tournament setup.

**Where:** **Setup → Tournament setup → Page builder**. Old "Event page" links open here too.

**To set the header image:** under **Page header**, click **Upload** (or pick from the library). It shows behind the tournament name on all event pages. **Remove** clears it.

**To arrange the page:**
1. Drag blocks to reorder them, or use **Move up** / **Move down**.
2. Click the eye to switch a block between **Visible** and **Hidden**.
3. Click the pencil (**Edit**) to edit a block right there. **Duplicate** and **Delete** work on added blocks.
4. Click **Save Changes**.

**Built-in blocks:** **Overview** (a summary), **Tournament fees** (pulled from Team fees), **Divisions** (pulled from Divisions), **Location** (pulled from Venues & fields), **Hotels** (a **Booking link (housing company)** shows as a **Book hotels** button), **Rules** (custom, or linked to a set in your **Rules library**), **Contacts** (**Add contact**) and **Sponsors & partners**. Empty sections never show.

**To add a block:** click **Add block** and choose **Custom text**, **Call-to-action button**, **Image / banner**, **Collapsible sections**, **Countdown**, **Schedule (live)** or **Standings (live)**. A custom block can sit on the event page or on **Its own page** linked from the Event info menu.

**To draft FAQs:** click **Generate FAQs from event details**. It builds a question-and-answer block from your dates, location, format, divisions, fees and registration. Edit or remove any after.

**Common problems:**
- Text boxes with **Generate with AI** can draft or reformat copy; check it before saving.
- Nothing goes live until you click **Save Changes**.
