Each event can have a rules page and extra info pages (for example an FAQ) set up by the organizer.

**Where:** **Rules** in the event page's **Event info** menu, the **Rules** section's **View** link, **Rules & policies** under **For players & parents**, or the **Rules** button on the Today page. Extra info pages open from sections on the event page.

1. The **Rules** page shows the full rules, format and policies for the event.
2. FAQ pages list questions; tap a question to read the answer.
3. Tap **Back to event page** to return.

**Common problems:**
- **Rules haven't been posted yet.** means the organizer has not added them. Check back, or ask the event contact.
- **This page has no content yet.** means the organizer has not filled that page in.
- For a rule question the page does not answer, contact the organizer listed under **Questions?** on the event page.
