The **Rules library** holds reusable rule sets, like Sixes or Traditional rules. Apply a set to many events and edits flow to every linked event. An event can still use its own custom rules on its event page.

**Where:** Home → **Admin** → **Rules library**.

**To create a rule set:**
1. Click **New rule set**.
2. Enter a **Name** and an optional **Format / tag (optional)**.
3. Write the **Rules**. You can use **Generate with AI** for help.
4. Click **Save**.

**To edit a rule set:** open it, click **Edit**, make changes, then click **Save**.

**To apply a set to events:**
1. Open the set and click **Apply to events**.
2. Tick each tournament that should use it. Untick to unlink.

A tournament already linked to another set shows "linked to another set".

**Common problems:**
- **Done** closes the editor but does not save. Click **Save** first.
- Deleting a set linked to events asks you to confirm. Those events fall back to their own custom rules.
