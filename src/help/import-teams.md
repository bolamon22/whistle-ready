Import adds many clubs and teams at once from a CSV or Excel file, for example a TourneyMachine Quick Report export.

**Where:** People → Team registrations → **Import teams**

**To import:**
1. Drop your file on the page or click to browse (.csv or .xlsx).
2. On **Map Columns**, check each column's match. Pick **— Skip this column —** for anything you don't need. Fields include Club Name, Team Name, Division, Coach Name, Coach Email, Coach Phone, Contact Name, Contact Email and Contact Phone.
3. Click **Preview Import**. Rows with the same club name are grouped into one registration.
4. Check the list and click **Import N Registrations**.
5. When it says **Import Complete!**, click **View Registrations**, or **Import Another File**.

**Common problems:**
- You must map at least **Club Name** or **Team Name** to continue.
- If a club has no contact name, the coach's name and details are used.
- Imported registrations get the note "Imported via spreadsheet upload" and no confirmation letter is emailed.
- Imported clubs are set to pay by check with no hotel; edit them afterward if that's wrong. Check each **Invoice Amount** too.
- If some rows fail, the finish screen lists the errors by club.
