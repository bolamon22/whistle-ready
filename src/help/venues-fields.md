Venues and fields are the places games are played. The Scheduler uses them as its columns, and venues with an address show on the public event page.

**Where:** **Setup → Tournament setup → Venues & fields**.

**To set the default hours:**
1. Under **Default field availability**, enter a start and end time for each tournament date.
2. Click **+ Add time slot** to add a second window on the same day.

**To add a venue and its fields:**
1. Type the venue name in **Venue / complex name** and click **+ Add Venue**.
2. Add fields: type a number in **How many fields?** to add Field 1, Field 2 and so on, or type one name in **Or add one:** (for example "2A" or "North").
3. Rename a field or change its **Abbr** right in the list. The **×** removes a field or venue.
4. Click **Save Changes**.

**To show a venue to teams and parents:** fill in the street address, and optionally a Google Maps link and a field map image URL. A map appears automatically from the address. Leave the address blank to hide the venue from the public page.

**To give one field its own hours or limits:**
1. Click **Availability** on that field.
2. Set **Available Hours** (**From** / **To**) for each day.
3. Under **Division restrictions**, tick the only divisions allowed on that field. None ticked means **All divisions**.

**Common problems:**
- To close a field for one day (rain, maintenance), use **Close today** on the Scheduler instead of deleting the field.
- Nothing is saved until you click **Save Changes**.
